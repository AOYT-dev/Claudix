# Claudix

Площадка с играми: Лимонный Икс и Лига Улиц. Общие аккаунты и облачные сохранения.

- `public/` — сайт (хаб и игры), раздаётся как статика
- `src/worker.js` — Cloudflare Worker: регистрация, вход, сохранения (база D1)
- `wrangler.toml` — настройки деплоя, сюда вписан Database ID базы `claudix-db`
